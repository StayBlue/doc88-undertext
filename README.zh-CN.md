# doc88-undertext

[English](README.md) | 简体中文

从道客巴巴下载可搜索的 PDF，自带文字层，无需 OCR。

道客巴巴在浏览器中渲染每一页时，会同时传来该页的原始文字和每个字符的位置。
本用户脚本把两者一起截取下来，生成每页图像下方都带有隐形文字层的 PDF，
因此可以选中、复制和搜索其中的文字。

## 安装

在 Tampermonkey（油猴）中安装
[`userscript/doc88-undertext.user.js`](userscript/doc88-undertext.user.js)。
脚本在 `https://*.doc88.com/p-*.html` 上运行，需要以下权限：`unsafeWindow`
（读取阅读器的页面内对象）、`GM_xmlhttpRequest`（获取手机版阅读器页面），
以及 `GM_getValue`、`GM_setValue` 和 `GM_registerMenuCommand`（用于语言设置）。

## 使用

打开文档，点击网站自带的下载按钮（**下载** 或 **下载此文档**）。按钮上会显示
截取进度，完成后自动下载 PDF。在手机版阅读器上，请改用脚本添加的
**下载 PDF** 按钮。

- 脚本不会绕过任何验证。遇到验证码时截取会暂停，在页面中完成验证后自动继续。
- 电脑版和手机版阅读器都支持。如果电脑版阅读器要求登录，或连续 5 页渲染失败，
  脚本会自动改用手机版阅读器，并以全屏覆盖层显示。
- 截取过程中请保持标签页可见。阅读器只渲染浏览器正在绘制的页面，
  标签页在后台时截取会暂停。
- 完成后的提示会列出未能截取或没有文字层的页面。
- 浏览器首选语言为中文时，提示显示中文，否则显示英文。可在 Tampermonkey
  菜单中点击 **Switch to English** / **切换到中文** 切换。
- 文字层使用 PDF 阅读器自带的字体，不嵌入字体文件：西文用 Helvetica，
  中文等其他文字用 STSong-Light。极少数超出 Unicode 基本多文种平面的字符会写成
  `?`。
